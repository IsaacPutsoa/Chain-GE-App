# Chain-GE — Responsive entrepreneurship opportunity platform

A front-end prototype built with plain HTML, CSS and JavaScript. It is designed around the promise: **“Hope is here now, not in future.”**

## Run locally
1. Extract `Chain-GE.zip`.
2. Open the `Chain-GE` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension for a local development server.

No build tools or package installation are required. Google Fonts are optional; the page falls back to system sans-serif fonts if offline.

## Prototype features
- Responsive dashboard with mobile navigation.
- Opportunity discovery with keyword search and filters for type and business stage.
- Opportunity detail modal with preparation guidance and demo-data disclaimer.
- Save/unsave opportunities; shortlist is persisted in browser `localStorage`.
- Entrepreneur network with search and industry filter.
- Editable entrepreneur/business profile with live preview and local save.
- Copy profile summary to clipboard.
- Keyboard focus styles, semantic labels, reduced-motion support and responsive layouts.

## Important prototype limitations
- Opportunity listings and entrepreneur cards are **illustrative demo data**, not verified live programmes or people.
- Profile and saved-opportunity data remain in the current browser on the current device. There is no account system, shared database, authentication, or cloud backup.
- Express-interest actions are demonstrations only; no message is sent.
- No funding is issued through this prototype. Verify organisations, eligibility, deadlines, fees and terms directly before sharing personal information or applying.

## Suggested production roadmap
1. Backend/API and secure database for users, organisations, opportunities and applications.
2. Verified organisation onboarding, moderation, fraud reporting and listing expiry.
3. Authentication, role-based access (entrepreneur / organisation / administrator), consent and account recovery.
4. Secure document uploads, privacy controls, audit logs, backups, rate limiting and security testing.
5. Application tracking, organisation dashboards, notifications, analytics and accessibility testing.
